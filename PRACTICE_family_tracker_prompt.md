## КОПИ-ПАСТ В GOOGLE AI STUDIO ↓↓↓

Ты — senior product-дизайнер и мобильный инженер. Спроектируй и собери **премиальное мобильное приложение** «Семейный трекер полезных привычек» (iOS-стиль). Не учебный прототип — готовый продукт уровня App Store: чистая навигация, светлая и тёмная темы, живые анимации, реальные демо-данные.

### Суть продукта
Одно приложение — на всю семью. У каждого члена семьи свои полезные привычки, плюс есть **общие семейные цели**. Геймификация без давления: серии (streaks), очки, награды от родителей, мягкие напоминания. Цель — чтобы семья вместе держала здоровые привычки в удовольствие, а не из-под палки.

### Пользователи и роли
- **Родитель / админ** — создаёт «семью», добавляет участников по коду-приглашению, ставит общие семейные цели, назначает награды и их стоимость в очках, видит прогресс всех.
- **Взрослый участник** — ведёт свои привычки + участвует в семейных целях.
- **Ребёнок** — упрощённый, крупный, дружелюбный режим: свои привычки с яркими иконками, очки за выполнение, награды. Без сложных настроек и без внешних соц-функций (безопасность детей).
- **Добавление пользователей** — родитель приглашает по коду семьи; у ребёнка профиль с аватаром, именем, возрастом и личным акцентным цветом.

### Экраны (собрать все)
1. **Онбординг** (3–4 экрана): зачем приложение → «Создать семью» или «Войти по коду» → добавить участников → готово. Тон мягкий, тёплый.
2. **Сегодня** (главная): карточки привычек на сегодня — выполнение одним тапом; кольцо прогресса дня; текущая серия; мини-лента семьи («Папа закрыл зарядку 🔥7»).
3. **Привычки**: список своих привычек; создание/редактирование в нижнем шите (название, иконка, цвет, частота — дни недели, время напоминания, цель/единица); архив.
4. **Семья**: участники с их прогрессом и сериями; **общие семейные цели** (напр. «Неделя без сахара», «100 000 шагов всей семьёй»); кнопка «Добавить участника».
5. **Детский режим** (профиль ребёнка): крупные карточки-привычки, прогресс-кольца, счётчик очков, награды-стикеры; всё проще и дружелюбнее взрослого вида.
6. **Награды**: каталог наград (их задаёт родитель — напр. «Поход в кино», «+1 час экранного времени»); стоимость в очках; обмен очков на награду с подтверждением.
7. **Статистика**: календарь-хитмап выполнения по дням, серии, тренды по неделям/месяцам, разбивка по участнику.
8. **Профиль / Настройки**: аватар, переключатель темы (светлая/тёмная), роли и доступы, приватность, выход.

### Дизайн-система (премиум)
- **Стиль:** тёплый, живой, premium-wellness — НЕ детсадовский. Полноценные **светлая и тёмная** темы (проектировать обе).
- **Палитра:**
  - Фон светлый `#FFFBEB` (тёплый кремовый) / тёмный `#1A1613`.
  - Текст/чернила `#0F172A` (светлая) / `#F5F0E8` (тёмная).
  - **Серии / стрики — янтарь** `#D97706`, доп. `#F59E0B`.
  - **Привычки / выполнено — зелёный** `#059669`.
  - Опасные действия `#DC2626`. Границы мягкие тёплые.
  - У детских профилей — индивидуальные акцентные цвета аватаров.
- **Типографика:** заголовки **Lora** (тёплая, человечная), текст **Raleway**. Шкала 12 / 14 / 16 / 20 / 24 / 32 / 40. Заголовки 600–700, текст 400, лейблы 500. Для цифр (очки, серии, таймеры) — табличные цифры.
- **Компоненты:** карточки с мягкими многослойными тенями, скругления 16–24px; прогресс-кольца; чекбоксы-таблетки; **нижняя таб-навигация ≤5** (Сегодня · Привычки · Семья · Награды · Профиль); FAB «+» для добавления; нижние шиты для создания; аватары участников.
- **Тени/elevation:** единая шкала мягких тёплых теней (напр. `0 8px 24px rgba(40,30,10,0.10)`), без рандомных значений.
- **Микроанимации (200–300ms, ease-out):** отметка привычки — пружинистый scale + искра/конфетти; рост серии — счётчик-роллап; получение награды — celebratory-вспышка; переходы между экранами — направленные. Уважать prefers-reduced-motion.
- **Иконки:** один аутлайн-набор (Lucide-стиль, обводка 1.5–2px), НЕ эмодзи как иконки.

### UX-правила (обязательно)
- Touch-таргеты ≥44pt, ритм отступов 8 / 16 / 24, safe-area сверху и снизу.
- Доступность: контраст ≥4.5:1 в обеих темах, accessibilityLabel на иконках, поддержка крупного системного шрифта без обрезаний.
- Детский режим: крупнее, проще, тёплые иллюстрации; родитель контролирует награды и доступы.
- Empty states с действием («Пока нет привычек — добавь первую»).
- Один главный CTA на экран; деструктивные действия отделены и красные с подтверждением.

### Демо-данные
Заполни реальной демо-семьёй: 2 родителя + 2 ребёнка, у каждого 3–4 привычки с разными иконками/цветами, активные серии, 1–2 общие семейные цели в прогрессе, пара наград в каталоге. Чтобы приложение сразу выглядело живым.

**Соберите целостное, премиальное приложение со всеми экранами, нижней навигацией, светлой и тёмной темами и живыми анимациями.**
