# Скриншоты для слайдов «результаты за месяц»

Положите сюда файлы с этими именами — слайды подхватят их при следующем запуске `./webinar.sh`:

- `bot.png` — слайд 46r «Сентябрь: ИИ-бот в директе»: скрин переписки или статистики бота;
- `blog-leads.png` — слайд 47r «Заявки с блога за месяц»: скрин заявок из CRM.

Цифры для этих слайдов — в `components/montage-deck/results.ts`. Имена файлов тоже там (`screenshot`).
Картинка вписывается в плиту целиком, ничего не обрезается; лучше вертикальный или квадратный скрин.
