## A. form-api: бот, расписание, переход в эфир, без EasyBot

Файлы: правка `form-api/server.ts`; новые `form-api/tg-time.ts`, `form-api/tg-store.ts`, `form-api/tg-workshop.ts`, `form-api/tg-scheduler.ts`, `form-api/tg-setup.ts`, тесты `form-api/tg.test.ts`.

Сборка (как текущий `form-api/dist/server.js`, cjs-бандл): `npx esbuild form-api/server.ts --bundle --platform=node --target=node20 --format=cjs --outfile=form-api/dist/server.js`. Так же собрать `form-api/dist/tg-setup.js`. Перед правками собери исходный `server.ts` и сравни поведение с `server.deployed.js` (маршруты, тексты ответов). Расхождения перечисли в отчёте.

### A1. server.ts
- Убрать EasyBot: `FUNNEL_REDIRECT`, `registerEasybotLead`, `resolveEasybotRedirect` и их импорты. Ответ `/api/lead`: `{ ok: true, redirect: "https://onai.academy/workshop-montazh/thank-you.html" }`. Константа `THANKYOU_URL` = этот адрес (используется и в `/api/tg-link`).
- `WHATSAPP_GROUP` удалить. Где нужна ссылка группы: `readWhatsAppLink()`.
- `/health`: `{ ok, funnel: "thank-you", thankYou, whatsapp: readWhatsAppLink(), tgBot: { configured: bool, seriesEnabled: bool, subscribers: number }, version }`. `version` из файла `VERSION` рядом с бандлом, иначе `"dev"`. Без секретов.
- `/calendar`: `details` = «Старт в 20:00 по Алматы. Ссылка на эфир придёт в группу WhatsApp или в Telegram-бот.», `text` = «Воркшоп «Вайб-продакшен» · onAI Academy».
- Роутер: `POST /api/tg-workshop` (вебхук), `GET /api/go/<token>` (переход в эфир). При старте процесса запустить планировщик (если есть токен).

### A2. Время (`tg-time.ts`)
Всё по поясу `Asia/Almaty` через `Intl` (возьми подход `lib/workshop-date.ts`: `partsInTZ`, `almatyWallToUTC`).
- `streamStart(dayKey)` = 20:00 этого дня по Алматы (из `streamStart` в json), `streamEnd` = старт + `streamMinutes`.
- `dayKey` = строка `YYYY-MM-DD` по Алматы.
- Назначение дня эфира подписчику при /start: если сейчас раньше `streamEnd(сегодня)`, то сегодня, иначе завтра. Во время эфира человек попадает на сегодняшний.
- `dayWord(D, now)`: «Сегодня», «Завтра» или «7 октября».

### A3. Хранилище (`tg-store.ts`)
Папка `DATA_DIR` (env, по умолчанию `join(__dirname, "data")`). Только дописывание строк JSONL, при старте читаем и собираем состояние в памяти.
- `tg-subscribers.jsonl`: события `start` (chat_id, user_id, username, first_name, language_code, payload, streamDay, ts), `blocked`, `unblocked`, `stop`, `paid` (by: self|owner), `rejoin` (streamDay).
- `tg-sent.jsonl`: `{ msg, day, chat_id, ts, ok, err? }`.
- `tg-clicks.jsonl`: `{ chat_id, day, ts }`.
- `tg-state.json` (перезапись через временный файл и rename): `{ seriesEnabled: false, media: { "<url>": "<file_id>" } }`.
Повторный /start: если день подписчика уже прошёл (`now >= streamEnd(D)`), назначить новый день и отправить приветствие; иначе только отправить приветствие заново. `stop` снимается новым /start.

### A4. Вебхук (`tg-workshop.ts`)
- Секрет в заголовке `X-Telegram-Bot-Api-Secret-Token` = `TG_WORKSHOP_WEBHOOK_SECRET`, сравнение `timingSafeEqual`, тело до 16 КБ. Отвечаем Telegram `200` сразу, работу делаем после ответа (исходящие запросы к Bot API с таймаутом 10 с).
- `/start [payload]` (payload `[A-Za-z0-9_-]{1,64}`, иначе пусто): записать, отправить приветствие из `welcome` json:
  - сейчас между `streamStart` и `streamEnd` дня D: текст `welcome.live` + кнопки `welcome.liveButtons`;
  - иначе: медиа `welcome.media` + подпись `welcome.before`.
- `/stop`: событие `stop`, ответ `welcome.stop`.
- Любой другой текст от не-владельца: `welcome.other`.
- `callback_query`: `paid` → событие `paid`, `answerCallbackQuery`, сообщение `welcome.paidAck`; `rejoin` → назначить день по правилу A2, ответ «Готово, ссылку пришлю сюда в 19:50.» (если сейчас идёт эфир: текст `welcome.live` с кнопкой).
- `my_chat_member`: `kicked` → `blocked`, `member` → `unblocked`.
- Команды владельцев (`TG_LINK_OWNER_IDS`), от остальных молча игнорировать:
  - `/stats`: всего, активных, на сегодня и на завтра, нажали ссылку сегодня, оплатили, по payload.
  - `/series`: включена ли серия; список сообщений на сегодня: время, id, аудитория, отправлено/кому.
  - `/series_on`, `/series_off`: флаг `seriesEnabled`.
  - `/preview`: прислать владельцу все сообщения серии по порядку (раз в 1,5 с), токены развернуть как для владельца, `{PAY}` пустой показать как кнопку менеджера. Это для проверки.
  - `/fire <id>`: отправить сообщение сейчас всем, кому оно положено на сегодня, и пометить отправленным, чтобы плановое не повторилось. Нужно, чтобы подстроиться под реальный ход эфира.
  - `/paid <chat_id или @username>`: пометить оплатившим.
  - `/reload`: перечитать `tg-series.json`, ответить версией и числом сообщений.

### A5. Подстановки
В тексте (parse_mode HTML, всё из json и имена пользователей экранировать: `& < >`): `{hi}` = «Привет, Имя!» или «Привет!», `{dayWord}`, `{dayWordLower}`, `{TEMPLATE}` = `links.template`.
В кнопках: `{STREAM}` = `https://onai.academy/workshop/api/go/<token>`, где token = base64url(`<chat_id>:<D>`) + `.` + первые 12 символов base64url(HMAC-SHA256(`TG_WORKSHOP_WEBHOOK_SECRET`, то же)); `{PAY}`, `{PREPAY}`, `{MANAGER}`, `{CASES}`, `{GAME}` из `links`; `{WHATSAPP_TEMPLATE}` = `links.whatsapp + "?text=" + encodeURIComponent(links.template)`. Кнопка с пустым адресом выпадает. Кнопка `callback` → `callback_data`.
У всех сообщений `link_preview_options: { is_disabled: true }`: Telegram не должен сам открывать ссылки и портить учёт переходов.

### A7. Планировщик (`tg-scheduler.ts`)
- Тик каждые 30 с. Работает, только если `seriesEnabled` и есть токен. Приветствие от флага не зависит.
- Для каждого сообщения (`enabled !== false`) и дня D: плановое время = D + `dayOffset` (по умолчанию 0) в `at` по Алматы. Отправляем, если сейчас в окне `[плановое, плановое + graceMinutes]`. Опоздали сильнее: пропускаем (лог `skip late`), не шлём «через час» в 20:40.
- Получатели: `streamDay == D`, не blocked, не stop, `registeredAt < плановое` (только что записавшимся прошлые сообщения не догоняем), ещё не получали `(msg, D)`. Аудитория: `all`; `notClicked` = нет клика за D; `notPaid` = нет события `paid`.
- Отправка последовательно, не быстрее 20 сообщений в секунду. `429`: ждать `retry_after`. `403` (бот заблокирован): событие `blocked`. Прочие ошибки: в `tg-sent.jsonl` с `ok:false`, без повторов.
- Медиа: первый раз по URL (`sendPhoto` / `sendVideo` с `supports_streaming`), из ответа взять `file_id` (фото: самый большой размер) и сохранить в `state.media`; дальше слать по `file_id`. Подпись к медиа не длиннее 1024 символов: если текст длиннее, медиа отдельно, текст с кнопками следом.
