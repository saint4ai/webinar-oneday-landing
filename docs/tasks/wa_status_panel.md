## 1. Блок «Статус WhatsApp» первым во вкладке

- Крупно состояние человеческими словами и цветом:
  - «Подключён» (номер, имя профиля, с какого времени);
  - «Ждёт подключения» (QR или код ещё не введены);
  - «Отключён» с причиной;
  - «Номер заблокирован WhatsApp»;
  - «Номер вышел из устройства (logout), нужно подключить заново»;
  - «Evolution не отвечает».
- Причину брать из Evolution: `GET /instance/fetchInstances?instanceName=<имя>`. Там поля `connectionStatus`, `disconnectionReasonCode`, `disconnectionObject`, `disconnectionAt`, `ownerJid`, `profileName`, `number`. Если в 2.3.7 поля называются иначе, проверь по исходнику Evolution 2.3.7 на GitHub (`src/api/services/channels/whatsapp.baileys.service.ts`, событие `connection.update`, `lastDisconnect.error.output.statusCode`).
- Коды Baileys `DisconnectReason`: 401 loggedOut, 403 forbidden (бан), 411 multideviceMismatch, 428 connectionClosed, 440 connectionReplaced, 500 badSession, 515 restartRequired. 403 и явные признаки бана показывать как «заблокирован». В фейковом Evolution (`wa-testkit.ts`) добавить эти состояния.
- Кнопка «Проверить сейчас» перечитывает состояние. Пока вкладка открыта, автообновление раз в 15 секунд.

## 2. Подключение двумя способами

- **По QR**: как сейчас.
- **По номеру телефона** (новое): поле номера (только цифры, 11–15, по умолчанию пустое) и кнопка «Получить код».
  - Сервер вызывает `GET /instance/connect/<инстанс>?number=<цифры>`, Evolution возвращает `pairingCode` (8 символов).
  - Пульт показывает код крупно, группами по 4, и инструкцию: «WhatsApp на телефоне → Настройки → Связанные устройства → Привязать устройство → Привязать по номеру телефона → ввести код». Код живёт около минуты, есть кнопка «Новый код».
  - Как только состояние стало `open`, показать «Подключён».
- Если номер уже подключён, обе кнопки спрятаны. Вместо них кнопка «Отключить номер» (logout, уже есть `logoutInstance`) с подтверждением внутри страницы, без `confirm()`.
- Маршруты под тем же `gateAdminSession`, что и остальные `/api/admin/wa/*`. Ключ Evolution и номер в логи не писать, номер в ответе маскировать (`7708***4575`).

## 3. Соадмины сообщества (СНЯТО Александром 08.10: номер единственный админ и полностью автоматический, никого не добавляем)

В текущей группе админ также партнёр Александра (Тимерлан), он пишет туда вручную. В новых сообществах он тоже должен быть админом.

- Переменная `WA_ADMIN_NUMBERS` уже есть (номера через запятую).
- В пульте кнопка «Сделать админом по номеру» у каждого сообщества из списка «Сообщества эфиров»:
  - поле номера;
  - сервер добавляет номер (`POST /group/updateParticipant/<инстанс>?groupJid=<jid>`, `action: "add"`) и повышает (`action: "promote"`);
  - для сообщества делает это и в родителе, и в группе объявлений (`sendJid`), если `jid` и `sendJid` различаются.
  - Результат по каждому шагу показать как есть: ок или текст ошибки.
- Автоматически после создания нового сообщества: тот же add и promote для каждого номера из `WA_ADMIN_NUMBERS` (шаг в `setupSteps` после настроек, с повтором как у остальных шагов). Ошибка шага не ломает остальное, только запись в журнал и одна тревога.
- Защиту «никого, кроме админ-номеров, не добавляем и в личку не пишем» не ослаблять.
