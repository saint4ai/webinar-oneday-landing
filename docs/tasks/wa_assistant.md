Номер сам создаёт сообщество эфира, он единственный админ и сам ведёт контент. К нему подключаем ИИ-бота, который отвечает участникам как ассистент Александра, помощник по воркшопу:
- воркшоп проходит каждый день в 20:00 по Алматы после регистрации на сайте;

- хочет всё узнать прямо сейчас → на Аяну.

## Механика

5. **Входящие.** Evolution шлёт вебхук `MESSAGES_UPSERT` на `http://127.0.0.1:4010/api/wa-hook`.
   - Вебхук инстанса ставит модуль сам: `POST /webhook/set/workshop` с `events: ["MESSAGES_UPSERT"]`, `webhook_by_events: false`, только при включённом ассистенте; при выключении снимает. Формат тела сверить с исходником Evolution 2.3.7 на GitHub.
   - Маршрут принимает запросы только с `127.0.0.1`, плюс общий секрет в заголовке, если Evolution 2.3.7 умеет свои заголовки вебхука. Иначе только проверка адреса.
6. **Отвечаем только в личке.**
   - Отвечаем: `remoteJid` на `@s.whatsapp.net` или `@lid`.
   - Не отвечаем: `@g.us`, сообщества, рассылки, статусы, свои (`fromMe`), реакции, системные.
   - Голосовые, фото, видео без подписи: одна фраза «Напишите, пожалуйста, текстом».
7. **Модель.** Только OpenAI: `gpt-5.6-luna` через `https://api.openai.com/v1/chat/completions`, ключ `OPENAI_API_KEY` из `.env`, `reasoning_effort: "low"`, `max_completion_tokens` около 1200, без temperature. Образец вызова в README базы (`app/llm.py`).
   - Нет ключа: ассистент не стартует, в пульте написано почему.
   - Сбой или таймаут 30 с: человеку ничего, одна тревога в час владельцам.
8. **История.** Последние 16 сообщений на человека в `data/wa-assistant.jsonl`, только текст. Номер в журнал и логи писать маскированным. В пульт показывать маскированный, полный только при нажатии.
9. **Защита номера от бана.**
   - Не больше 1 ответа на одно входящее; если человек прислал пачку, отвечать раз на всю пачку, подождав 8 с тишины.
   - Не больше 30 ответов одному человеку в сутки.
   - Не больше 400 ответов на номер в сутки.
   - Пауза 2–5 с перед ответом, плюс «печатает…» (presence `composing`), если Evolution 2.3.7 это даёт.
   - Сверх лимитов молчим, владельцам одна тревога.
   - Первыми никому не пишем никогда.
10. **Проверка ответа перед отправкой.** Не уходит, если в ответе:
    - цифры с «₸», «тенге», «$», «руб» или слова «рассрочка», «стоит» рядом с числом;
    - ссылки не из белого списка (`onai.academy/workshop-montazh/...`, `wa.me/77085834575`, `t.me/futleid`, `t.me/workshop_aiprod_bot`);
    - слова «The One System», «Erickson», «Жумабаев».

    Тогда второй запрос модели с замечанием. Снова не прошёл: безопасная заготовка «Подскажет менеджер школы: https://onai.academy/workshop-montazh/chat».
11. **Пульт, блок «ИИ-ассистент»** во вкладке «WhatsApp»:
    - переключатель вкл/выкл (по умолчанию выкл, хранится в `wa-state.json`);
    - счётчики за сегодня: диалогов, ответов, передано Аяне, отклонено проверкой;
    - последние 20 диалогов (маскированный номер, последнее сообщение, ответ);
    - поле «Проверить ассистента»: вопрос → ответ модели без отправки в WhatsApp.

    Маршруты под `gateAdminSession`.
12. **Команды в боте:** `/wa_ai on|off`, `/wa_ai_test <вопрос>`.

## Не делать

- Не менять поведение при выключенном `WA_GROUPS` и при выключенном ассистенте: ни вебхука, ни запросов к OpenAI.
- Не трогать серию, рассылки, лендинг, Instagram-бот.
