# Воронка воркшопа: страница «Спасибо» с выбором WhatsApp/Telegram + бот @workshop_aiprod_bot

План Opus от 06.10.2026 для исполнителя (Sonnet). Решения Александра от 06.10.2026:

- EasyBot отменён целиком, сбор только в группы.
- На странице «Спасибо» **нет автоперехода**. Человек выбирает: группа WhatsApp или Telegram.
- Telegram = бот **@workshop_aiprod_bot** («Воркшоп AI продакшн @saint4ai», id 8837496978). Пока он только регистрирует и шлёт приветствие. Рассылки запускаем **только после** того, как Александр посмотрит серию в презентации (Claude Artifact).

Общие правила: без длинных тире «—» в новых текстах для людей, ответы Александру по-русски и коротко. Деплой на сервер только по «го», одним заходом (один ssh-скрипт, без циклов). ## Задача 4. Бот @workshop_aiprod_bot (внутри form-api, вебхук)

Новый модуль `form-api/tg-workshop.ts`, маршрут `POST /api/tg-workshop` в роутере `server.ts`. Сначала проверить в nginx (`/etc/nginx/sites-enabled/onai.academy`, блок `location ^~ /workshop/api/`), что `/workshop/api/X` уходит на `:4010/api/X` (так работает уже `/api/tg-link`). Новая nginx-конфигурация не нужна.

**Переменные в `/opt/workshop-form/.env`** (дописать, старые не трогать):
`TG_WORKSHOP_BOT_TOKEN`, `TG_WORKSHOP_WEBHOOK_SECRET` (случайные 48 символов `[A-Za-z0-9]`), `WORKSHOP_START=2026-10-07T20:00:00+05:00` (сверить с `efir.js`), `WORKSHOP_NAME` (ждём от Александра), `WORKSHOP_LINK=` (пусто, ссылку на эфир дадим завтра).

**Обработка апдейтов**
- Секрет из заголовка `X-Telegram-Bot-Api-Secret-Token`, сравнение за константное время (как `secretOk`), тело до 16 КБ.
- `message` с текстом `/start` или `/start <payload>`: записать подписчика, ответить приветствием.
- `my_chat_member` со статусом `kicked`: пометить `blocked: true`. Статус `member` снова: `blocked: false`.
- Любой другой текст от не-владельца: короткий ответ «Ссылку на эфир пришлю сюда <день> в <время> по Алматы. Бот работает сам, на сообщения не отвечает.»
- Владельцы (`TG_LINK_OWNER_IDS`): команда `/stats`: всего, активных (не blocked), за сегодня, по источникам (`payload`).
- Ответ слать через тело вебхука (`{ method: "sendPhoto" | "sendMessage", ... }`), как `webhookReply`: без исходящего запроса, хендлер не зависает. Сначала запись в хранилище, потом ответ.

**Хранилище:** `/opt/workshop-form/data/tg-workshop.jsonl`, только дописывание строк-событий (`start`, `blocked`, `unblocked`) с `chat_id`, `user_id`, `username`, `first_name`, `language_code`, `payload`, `ts`. При старте процесса читать файл и собирать карту подписчиков в памяти. Папку `data/` создать с владельцем onaiapp.

**Приветствие** (`sendPhoto`, подпись до 1024 символов, `parse_mode: "HTML"`; картинка = аватарка бота по публичному URL, например `https://onai.academy/workshop-montazh/assets/tg/avatar.jpg`):

```
Добро пожаловать на воркшоп<, Имя>!

<Завтра|Сегодня|7 октября> в 20:00 по Алматы пришлю сюда ссылку на воркшоп «<WORKSHOP_NAME>».

Что разберём:
1. Монтаж рилса вживую. Записываю голос, агент собирает графику, субтитры и звук.
2. Презентация по брифу. Агент делает структуру, тексты и слайды без дизайнера.
3. Приложение из одного ТЗ. Покажу, что с ним делать и сколько такое стоит на рынке.
Плюс шесть форматов рилсов, в том числе без лица.

Записи не будет, приходите вживую. В конце эфира здесь же выдам бонусы: три гайда и скидку участникам.
```

- День считать от `WORKSHOP_START` по часам Алматы (UTC+5): та же дата = «Сегодня», следующая = «Завтра», иначе «7 октября».
- Если эфир уже начался и `WORKSHOP_LINK` задан: вместо первой строки «Эфир уже идёт, заходите: <ссылка>».
- Если эфир закончился (старт + 80 мин): «Эфир прошёл. Бонусы и запись новостей пришлю сюда.» (финальный текст уточним в серии).
- Текст держать в одном месте (`tg-workshop.ts`, функция `welcomeText`), чтобы Opus потом заменил его без правки логики.

**Разовая настройка бота** (скрипт `form-api/tg-setup.ts`, запуск на сервере вручную после деплоя):
- `setWebhook`: `url=https://onai.academy/workshop/api/tg-workshop`, `secret_token`, `allowed_updates=["message","my_chat_member"]`. Ожидающие апдейты не сбрасывать.
- `setMyProfilePhoto` с `InputProfilePhotoStatic` (загрузка файла multipart, `attach://`), картинка ждёт решения Александра.
- `setMyDescription`: «Бот бесплатного воркшопа onAI. Пришлю ссылку на эфир и бонусы. Нажмите «Запустить».»
- `setMyShortDescription`: «Ссылка на воркшоп и бонусы участникам»
- `setMyCommands`: `/start` «Записаться на воркшоп».
- В конце `getWebhookInfo` и `getMe` в лог (без токена).

**Рассылка (только инструмент, не запускать):** `form-api/tg-broadcast.ts`: `--file message.json` (текст/фото/видео + кнопки), `--dry-run` (сколько получит), `--test <chat_id>` (одному), `--all`. Не больше 20 сообщений в секунду, на 429 ждать `retry_after`, на 403 писать событие `blocked`. Отчёт в `data/broadcast-<ts>.log`. Запуск `--all` только после одобрения серии Александром.

## Деплой (одним ssh-заходом, только по «го»)

Ключ `~/.ssh/onai_codex_windows`, скрипт через base64 (`echo <b64> | base64 -d | bash`), иначе BOM и `\r` из PowerShell ломают bash. pm2 так: `runuser -u onaiapp -- env PM2_HOME=/home/onaiapp/.pm2 pm2 ...`.

1. Бэкап: `cp -a /var/www/workshop-montazh /var/www/workshop-montazh.bak.<ts>`, `server.js` и `.env` в `*.bak.<ts>`, старая Next thank-you в `.bak.<ts>`.
2. Залить thank-you.html, efir.js, аватарку `assets/tg/avatar.jpg`, новый `server.js`, `tg-setup.js`, `tg-broadcast.js`; дописать переменные в `.env`; `VERSION`.
3. `pm2 restart workshop-form`, подождать `/health`.
4. `node tg-setup.js`.
5. `funnel-check` и `getWebhookInfo`. Отчёт Александру: что выложено, PASS-таблица, как откатить.
6. Попросить Александра нажать /start в боте и прислать /stats: это живая проверка.

Откат: вернуть каталоги и файлы из `.bak.<ts>`, `pm2 restart workshop-form`, `deleteWebhook`.
