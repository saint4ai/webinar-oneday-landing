## 2. Архитектура: всё через токены, а не через 76 слайдов

Слайды почти везде берут цвета из `T` (`components/montage-deck/theme.ts`) и общие стили `card`, `glass`, `goldButton`, `nightCard`. Поэтому основная работа идёт в четырёх файлах, и вся колода меняется разом:

1. **`theme.ts`**
   - Добавить `export const GLASS = true`.
   - При `GLASS` переопределить светлые токены на ночные (таблица ниже).
   - `card` и `glass` сделать стеклом.
   - Добавить `glassStrong` для карточки, которая должна читаться поверх видео или скрина.
2. **`MontageBg.tsx`**: при `GLASS` любой тон (`paper`, `soft`, `night`) рисует ночной фон со свечением. Свечение: 2–3 радиальных пятна (золото `rgba(227,192,123,.35)`, коричневый `rgba(160,83,42,.45)`), размытие, медленный дрейф 12–18 с, как на 08c. Пятна только в левых 60%, справа фон ровный.
3. **`ui.tsx`**: `H`, `Em`, `Kicker`, `Lead`, `Note`, `Num`, `Chip`, `Rise` берут цвета из токенов. Проверить, что нигде не зашит светлый цвет литералом.
4. **`Statement.tsx`**: по умолчанию `tone` ночной, если `GLASS`.

## 3. Типографика

Решение за Александром, в плане два варианта. Перед стартом спросить одним вопросом с двумя картинками: снять слайды 08c и 10 в обоих вариантах.

- **А (быстрее, меньше риска):** остаётся Unbounded 800, меняется только цвет. Заголовок тёплый светлый `#F3E3C3`, акцент-слово золотом.
- **Б (как на сайте):** `H` на Manrope 600, `letter-spacing: -0.03em`, `lineHeight 1.08`, размер ×1.1 от нынешнего. ## 5. Шаги и проверки

1. **Ветка-страховка.** `git switch -c glass/deck-<время>` от `deck-wave2`. Все коммиты в неё. В `deck-wave2` вливать только после «да» Александра.
2. **Токены, фон, стекло, типографика** (разделы 2–3). После этого `npx tsc --noEmit -p .` и сборка:
   ```powershell
   $env:WEBINAR_LOCAL="1"; for ($k=1; $k -le 4; $k++) { npx next build *> $env:TEMP\deckbuild.log; if ($LASTEXITCODE -eq 0) { "ok $k"; break } }
   ```
3. **Съёмка всей колоды** и общий лист:
   ```powershell
   node docs/deck-v2/shoot-offline.mjs --out <скретчпад>\glass --w 960
   ```
   Собрать лист 6×13 миниатюр (sharp: сначала `composite` в буфер, потом `resize`, иначе `resize` применится до `composite`). Пройти лист глазами по таблице раздела 4.
4. **Правки по слайдам** из раздела 4. Снимать только изменённые: `--only "08,10g"`. Скрипт прыгает на слайд по `#N`, пролистывания нет.
5. **Контраст.** Текст на стекле не ниже 4.5:1. Если стекло стоит поверх яркого видео или скрина, взять `glassStrong`: заливка 14–18%, размытие 28px.
6. **Зона камеры.** Скрипт пишет `⚠ зона камеры` для всего, что правее 60%. Свечение и пятна фона туда не заходят, их `right` упирается в колонку.
7. **Производительность.** Это эфир, браузер ещё тянет OBS. На одном слайде не больше 4–5 элементов с `backdrop-filter`. Если слайд дёргается при листании, убрать размытие у мелких пилюль и оставить только у крупных панелей.
8. **Показ Александру.** Лист всей колоды и 3–4 крупных кадра (обложка, 08c, 10, слайд цены) отправить в чат. Ждать «да».
9. **Страница для партнёров.** После «да» переснять кадры и видео (команда в `docs/tasks/cases_pack_sonnet.md`, шаг 5, плюс `--clips` для слайдов с видео) и опубликовать по той же ссылке.
