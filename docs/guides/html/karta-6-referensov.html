Промпт для Claude

Ты монтажёр вертикальных рилсов. Смонтируй рилс 1080×1920 из моего видео (файл прикрепляю). Формат «Половина экрана». Нижняя половина кадра: я говорю в камеру. Верхняя половина: графика по смыслу моих слов (шаги, сервисы с настоящими логотипами, крупные цифры), новая сцена каждые 3–5 секунд. Субтитры крупные, по 2–4 слова, на стыке половин, текущее слово подсвечено. Первые 3 секунды: обещание ролика в 4–6 словах крупно. Собери в Remotion, установи его сам, если его нет. Сначала покажи карту сцен, потом кадры каждые 2 секунды, финал рендери после моего «ок».

Без лица
Промпт для Claude

Ты монтажёр вертикальных рилсов. Смонтируй рилс 1080×1920 из моего голоса (аудио прикрепляю), меня в кадре нет. Формат «Без лица». Весь экран: графика по смыслу каждой фразы. Первые 3 секунды: самая сильная цифра или результат крупно. Собери в Remotion, установи его сам, если его нет. Покажи карту сцен и кадры каждые 2 секунды, финал после моего «ок».

Промпт для Claude

Ты монтажёр вертикальных рилсов. Сделай нарезку 1080×1920 из записи разговора (видео прикрепляю). Формат «Подкаст». Найди 3 отрывка по 30–60 секунд с законченной мыслью и сильной первой фразой и покажи мне список с таймкодами. Для выбранного отрывка: снизу разговор, в кадре тот, кто говорит; сверху доска, на которой появляются пометки по смыслу: тезисы, цифры, галочки. Субтитры крупные, по 2–4 слова. Первые 3 секунды: самая цепляющая фраза отрывка. Собери в Remotion, установи его сам, если его нет. Кадры каждые 2 секунды, финал после моего «ок».

Как пользоваться промптом

1
Откройте Claude на компьютере и начните новый чат.
2
Прикрепите свою запись: видео или голос с телефона.
3
Вставьте промпт формата и правьте словами: «субтитры крупнее», «подними меня выше».
Команды в терминале не нужны: Claude сам ставит всё, что нужно для монтажа.
