# Шаблон WABA: «вы ещё не вступили в сообщество» (onai web bot, этап C)

Создаётся в кабинете Wazzup: «Шаблоны сообщений» → «Шаблоны WABA» → «+ Добавить шаблон» → «Отправить на модерацию». Модерация обычно 2–3 часа, иногда до 1–2 дней.

Ссылка в кнопке постоянная: `https://onai.academy/workshop-montazh/wa`. Наш сервер сам переадресует её в сообщество того эфира, на который записан человек. Так один шаблон работает для всех будущих сообществ. Динамическую ссылку Wazzup через API не заполняет, поэтому она не нужна.

Подаём два шаблона: дешёвый служебный и маркетинговый запасной. Если Meta переведёт первый в маркетинговый, просто пользуемся вторым.

## Шаблон 1 (служебный, около 16 ₸ в Казахстане)

- **Название:** `vstupite_v_soobshchestvo_1`
- **Категория:** «Оповещения, напоминания, вопросы для клиентов» (UTILITY)
- **Язык:** русский
- **Заголовок:** нет
- **Основной текст:**

```
Здравствуйте, {{1}}! Вы записаны на воркшоп «Вайб-продакшен» {{2}} в 20:00 по Алматы.

Ссылка на эфир придёт в сообщество участников в WhatsApp, а вас там пока нет. Нажмите кнопку ниже, и мы пришлём ссылку для входа.
```

- **Примеры переменных:** {{1}} «Айгерим»; {{2}} «сегодня, 9 октября»
- **Подпись:** `onAI Academy`
- **Кнопка:** быстрый ответ «Пришлите ссылку»

Как работает: человек жмёт «Пришлите ссылку», ответ открывает окно 24 часа, сервер сразу присылает обычным сообщением ссылку на сообщество (бесплатно).

## Шаблон 2 (маркетинговый, около 54 ₸, вход одним нажатием)

- **Название:** `vstupite_v_soobshchestvo_2`
- **Категория:** Marketing
- **Язык:** русский
- **Заголовок:** нет
- **Основной текст:**

```
Здравствуйте, {{1}}! Вы записаны на воркшоп «Вайб-продакшен» {{2}} в 20:00 по Алматы.

Ссылку на эфир, напоминания и материалы мы присылаем в сообщество участников в WhatsApp. Вы в него ещё не вступили, вход по кнопке ниже.
```

- **Примеры переменных:** {{1}} «Айгерим»; {{2}} «сегодня, 9 октября»
- **Подпись:** `onAI Academy`
- **Кнопка:** ссылка «Вступить в сообщество» → `https://onai.academy/workshop-montazh/wa`

## Когда отправляем (настраивается в пульте)

1. Через 30 минут после записи, если человек не перешёл по ссылке сообщества и не вступил: шаблон 1.
2. В день эфира в 15:00 по Алматы, если всё ещё нет: шаблон 2.
3. Не больше двух шаблонов на человека, ночью (22:00–09:00 по Алматы) не пишем, лимит нового уровня 250 человек в сутки.

## Что нужно, чтобы подать

- Шаблоны создаёт Александр или Аяна в кабинете Wazzup (через API их может создавать только техпартнёр).
- Страница `https://onai.academy/workshop-montazh/wa` должна работать до подачи: Meta открывает ссылку при модерации. Её делает исполнитель пульта.
- В форме записи согласие на сообщения в WhatsApp и звонки (для России обязательно).
