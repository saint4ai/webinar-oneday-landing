# Сквозная аналитика воркшопа: креатив → заявка → сообщество → эфир → покупка

08.10.2026, сессия «Вебинар», запрос Александра: «с какого креатива лид попал в группу, а затем в Бизон… по ссылке на вебинар определять UTM, лида и телефон, отслеживать доходимость, сопоставлять с кампаниями в Facebook и YouTube».

Источники: исследование 08.10 (документация Bizon 365 API v1, Meta Marketing API, Google Ads ValueTrack и GAQL), ссылки в отчёте исследования. Что не подтверждено документацией, проверяем тестом до запуска (раздел «Проверки»).

## Итоговая таблица, ради которой всё

По каждому объявлению (`ad_id`) и дню:
- расход;
- заявки;
- вступили в сообщество или бот;
- кликнули ссылку эфира;
- пришли на эфир;
- смотрели 30+ минут;
- дошли до оффера;
- купили (предоплата, полная).

Из этого считаем цену заявки, цену зрителя и цену покупки по креативу. Показ: вкладка «Креативы» в Mini App админке бота и ежедневная сводка в Telegram.

## Что уже есть

- Лендинг сохраняет `utm_*` в заявке (`form-api/server.ts`, поле `utm`), отчёты по UTM в админке (`tg-admin.ts`).
- Кнопка Telegram на «Спасибо» несёт код заявки (`start=<src>_<eventId>`), бот знает, чья это заявка.
- Личная ссылка на эфир: `/api/go/<токен>` пишет клик и делает 302 на Bizon.

## Схема

1. **Метки в рекламе, только ID (имена меняются).**
   - Meta, поле объявления «URL parameters» (в API `url_tags` креатива): `utm_source={{site_source_name}}&utm_medium=paid&utm_campaign={{campaign.id}}&utm_term={{adset.id}}&utm_content={{ad.id}}`. Ставит сессия «Таргетолог» через скилл AI-таргетолога на все активные объявления воркшопа.
   - YouTube (Google Ads), Final URL suffix на уровне аккаунта: `utm_source=youtube&utm_medium=video&utm_campaign={campaignid}&utm_term={adgroupid}&utm_content={creative}`. Автопометку включить, лендинг сохраняет `gclid`, `gbraid`, `wbraid`.
   - Органика из Instagram Александра остаётся как сейчас (`utm_source=instagram` из ссылок в био и директе).
2. **Лендинг.** Добавить сохранение `fbclid`, `gclid`, `gbraid`, `wbraid` и короткий `lead_token` (уже есть `eventId`, им и пользуемся).
3. **Сообщество или бот.**
   - **Telegram:** вход по `start=` (есть).
   - **WhatsApp:** по номеру. Патч Evolution: `getLIDForPN(номер заявки)` и сверка с LID в заявке на вступление. Это задача onai web bot, см. `wa-communities-plan.md`. До неё приблизительно, по клику на ссылку сообщества.
4. **Ссылка на эфир.** `/api/go/<lead_token>` → `https://start.bizon365.ru/room/196985/BguY0kXF-l?<свой_параметр>=<lead_token>&username=<имя>&autologin`.
   - Телефон в ссылку не кладём.
   - Имя своего параметра задаётся в настройках комнаты Bizon (вкладка «Доступ», проверить). В отчёте Bizon он приходит как `cu1`.
5. **Отчёт Bizon после эфира.**
   - Вебхук `webinarEnd` (комната → «Разное → После вебинара» или «Домен и общие параметры → Вебхуки») на наш `/workshop/api/bizon-hook`.
   - Сервер забирает `reports/get?webinarId=` (там `cu1`, `utm_*`, `vi`, `buttons`, `banners`, `finished`) и `reports/getviewers` (листать по 1000).
   - Сырой JSON храним у себя: Bizon держит отчёты 92 дня.
   - Авторизация заголовком `X-Token`. Токен берётся в Bizon: «Модераторы, сотрудники».
6. **Сшивка зрителя.**
   - Сначала `cu1 = lead_token`, потом нормализованный телефон, остальные в «несопоставленные».
   - Минуты считаем объединением интервалов `vi` по всем входам одного токена.
7. **Покупка.** В кнопках и баннерах оплаты в комнате ссылка `…?lead={{cu1}}` (шорткод Bizon). Плюс ручная отметка оплаты `/paid` в боте, она уже есть. Запасной ключ телефон.
8. **Расходы.** Ночная задача, раз в сутки, вчера и сегодня, в таблицу `ad_spend(platform, ad_id, date, spend, name, thumb)`:
   - Meta: `GET /act_<id>/insights?level=ad&fields=ad_id,ad_name,spend&time_increment=1`;
   - Google: GAQL по `ad_group_ad` (`cost_micros / 1e6`).

## Проверки до запуска (один тестовый проход)

- Вход в комнату по ссылке с `autologin` и своим параметром: появились ли `cu1` и `utm_*` в `reports/get`. Документация этого прямо не обещает.
- Meta `{{site_source_name}}` и `{{placement}}` реально подставляются (тестовый клик по превью объявления).
- Google Demand Gen: подставляются ли `{campaignid}`, `{adgroupid}`, `{creative}`.
