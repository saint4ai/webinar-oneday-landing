# Агенту на Windows: презентация эфира Vibe Production и интро-ролик

Прочитай целиком до работы. Здесь всё, что было в контексте на маке: что за проект, как запустить, правила, статус и следующая задача.

## Что это

- **Презентация живого эфира Vibe Production**: вторник, 6 октября 2026, 20:00 по Алматы, около часа. Next.js 16, маршрут `/montage`. Александр показывает её со своего компьютера, его камера в OBS занимает правые 40% кадра.
- **Вступительный ролик**: идёт первым слайдом (00). Голос готов — версия v5. Монтаж делает Codex, готовый ролик кладёт в `public/montage/intro.mp4`.
- Продукт — месячное обучение Vibe Production: AI-монтаж, AI-креатор, ассистенты и автоматизация.

| Ты | Начни с |
|---|---|
| Монтируешь интро | `docs/intro-video/HANDOFF.md`; голос — `docs/intro-video/audio/intro_voice_v5.wav` |
| Продолжаешь презентацию | этот файл → `docs/tasks/deck_wave2.json` |

## Установка на Windows, один раз

Нужны Node.js 20.9+ (проверено на 22), Git и Chrome.

```powershell
git config --global core.autocrlf false
git config --global core.longpaths true
git clone -b feat/deck-1920-zone40 https://github.com/saint4ai/webinar-oneday-landing.git
cd webinar-oneday-landing
npm ci
```

`autocrlf false` — чтобы скрипты и JSON не получили переводы строк Windows.

## Запуск

| Зачем | Команда | Адрес |
|---|---|---|
| Правки, горячая перезагрузка | `npx next dev -p 3001` | http://localhost:3001/montage |
| Показ на эфире, прод-сборка | `powershell -ExecutionPolicy Bypass -File .\webinar.ps1` | http://localhost:3001/montage |

- `webinar.ps1` собирает начисто, около минуты, и поднимает сервер. Без `WEBINAR_LOCAL=1` в прод-сборке картинки и видео отдают 404 — скрипт ставит переменную сам.
- Листание — стрелки и пробел. На слайде 00 ролик запускается со звуком по Enter или клику. Номер слайда — в левом нижнем углу.

## Правила — не нарушать

1. **Правые 40% кадра — камера Александра. Там пусто:** ни текста, ни картинок, ни телефонов, ни эффектов, только фон слайда. `shoot.mjs` печатает «⚠ зона камеры», если что-то туда залезло.
2. **Бренд — как сайт onai.academy:** ночь `#14100E` и `#211A16`, золото `#E3C07B` → `#C9A05A`, коричневый `#A0532A`, крем `#FBF3E4`, шрифты Unbounded и Manrope. Лайм, неон и чёрный `#000` прошлых воркшопов — нельзя.
3. **Цены:** полная 250 000 ₸; участникам эфира 150 000 ₸; рассрочка от 6 250 ₸ на 24 месяца; бронь 10 000 ₸ входит в цену; за прохождение игры Token Runner ещё −10 000 ₸, итого 140 000 ₸. В самой игре своя цепочка 241 400 → 140 000 — её не выравнивать. Процент скидки на слайдах не писать.
4. **Цифры — только из раздела «Факты» и `docs/social-30d/`.** Продажи не называть — решение Александра. Зрителей разных площадок не складывать в «людей». 852 подписки — без «за 30 дней». 825 701 — это просмотры, а не охват.
5. **Практика 2 — презентация, не договор.** Договор вживую не делаем.
6. **`<Fill>` на слайде — пропуск, который заполняет Александр.** Не выдумывай содержимое. Открытые пропуски — ниже.
7. **Тексты на экране — коротко и по делу**, без воды и штампов. Не уверен в формулировке — спроси Александра.
8. **Git:** коммит на каждую правку, работа в своей ветке. Push и слияние — только с разрешения Александра. Ключи и `.env` не коммитить.
9. Не править `components/sales-deck/` (общие компоненты других дек), `components/montage-deck/fx/` и маршруты `/sales-deck`, `/webinar-60`.

## Открытые пропуски — спросить Александра

- 08 — выпускников «1000+» или «900+».
- 08w — хронология: сколько часов уходило на монтаж раньше; «месяцы» в строке «2 месяца учил агентов».
- 09 — ставка монтажёра 10 000 ₸ за ролик.
- p2b — пример презентации, собранной агентом: бриф, результат, время и скрин `public/montage/results/doc-example.png`.
- p3f, p3h — цифры со старого воркшопа: «в 2–3 раза дешевле студии», «5 человек × 6 месяцев» и «1 человек × 1 неделя».
- 57 — поддержка: формат и кто отвечает.
