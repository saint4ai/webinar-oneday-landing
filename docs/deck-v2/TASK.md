# Задача: дека эфира Vibe Production v2 (`/montage`)

Эфир — четверг, 1 октября 2026, 20:00 по Алматы. Дека показывается с компьютера: `./webinar.sh` → `http://localhost:3001/montage`.

## Прочитать первым
1. `docs/deck-v2/РЕЖИССУРА.md` — визуальная система, зона камеры, ритм, раскадровка по блокам, слайды результатов. Решения не пересматривать.
2. `components/montage-deck/MontageDeck.tsx` и `slides/*` — текущая дека, 60 слайдов. **Тексты и цифры на слайдах утверждены — не менять.**
3. `components/montage-deck/fx/` — объёмные эффекты. Стенд: `/montage-fx?fx=tunnel|voxel|number|screen|funnel|cost`.

## Два правила владельца — нарушение = переделка
- **Правые 40% кадра — зона камеры. Там только фон слайда.** Ни картинок, ни телефонов, ни эффектов, ни текста.
- **Бренд — как у сайтов onai.academy**, токены в `fx/brand.ts` и в разделе 1 режиссуры. Лайма `#B6FF00`, оранжа `#FC5C02`, чёрного `#050505`, `CyberpunkChapter`, `GlitchText`, зелёного логотипа быть не должно.

## Порядок
1. **Эффекты под бренд.** `fx/brand.ts` готов, `ReelTunnel3D` уже перекрашен и гаснет к зоне камеры. Перекрасить остальные пять: `VoxelField` (ночной фон, золото, маска `CAMERA_SAFE_MASK`), `ExtrudedNumber` (коричневый `#A0532A`, толщина в тёплых тёмных тонах, шрифт Unbounded), `ScreenStage3D` (белая плита, рамка `line`, тёплая тень, золотой свет), `LeadFunnel3D` (для ночного слайда: кольца золотом, частицы `#FBF3E4`, подписи Unbounded/Manrope), `CostDrop3D` (плиты коричневые → золотые, суммы Unbounded). API не менять. Коммит.
2. **Тема.** `components/montage-deck/theme.ts` — токены сайтов из `fx/brand.ts`. Шрифты Unbounded + Manrope уже подключены. Коммит.
3. **Обложка 01 и главы 11, 24, 33, 42, 51** — по раскадровке. Коммит.
4. **`results.ts` и три слайда результатов 22r, 46r, 47r** — раздел 5 режиссуры. Коммит.
5. **Остальные блоки** по раскадровке, коммит на блок.

## Как работать
- Ветка `claude/deck-v2` от `feat/deck-1920-zone40`. Коммит после каждого шага, push в свою ветку. В `feat/deck-1920-zone40` и `main` не сливать.
- Менять только `components/montage-deck/`, `app/montage/`, `public/montage/`, `docs/deck-v2/`. `components/sales-deck/` — только импорт: эти файлы общие с другими деками.
- Без новых npm-пакетов. Секреты и `.env` не открывать.
- Сетку слайда — через `SlideLayout` / CSS Grid, не абсолютом. Единицы — `cqw`/`cqh` (рамка 1920×1080 с `container-type: size`).
- framer-motion: не смешивать CSS `transform` с анимацией `x/y/scale` на одном элементе — центрировать через motion-пропсы `y: "-50%"`. Анимировать между одинаковыми единицами (`"1.5cqw"` → `"0cqw"`, не → `0`).

## Проверка перед каждым коммитом
- `npx tsc --noEmit` — 0 ошибок; `npx next build` проходит.
- Если есть Chromium/Playwright: скриншот каждого изменённого слайда 1920×1080, листать `document.dispatchEvent(new KeyboardEvent('keydown',{key:'ArrowRight',bubbles:true}))`, ждать 2,5 с после листания. Сохранять JPEG шириной 960 в `docs/deck-v2/shots/NN.jpg` и коммитить — по ним владелец и Claude смотрят без запуска. Глазами: правее 60% ширины — только фон; ничего не обрезано и не наезжает; цвета только из бренда.
